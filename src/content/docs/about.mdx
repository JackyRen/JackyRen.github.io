# About

This is Jacky Ren's bilingual writing space for engineering notes, publishing systems, and agent workflows.

The site is built with Astro Starlight and deployed as a static GitHub Pages site. Content lives in the `docs` collection so posts, metadata, sidebar navigation, and search are handled by the same documentation architecture.
